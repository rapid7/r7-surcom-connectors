# __Description__

  Connector for Nudge Security

# __Overview__

  Nudge Security is a SaaS security platform that discovers and manages every SaaS application in an organization's environment without requiring agents or network changes.

  This connector imports SaaS apps, user accounts, groups, OAuth grants, and security findings from the Nudge Security API into Surface Command.

# __Documentation__

  This connector requires an `API Token`.

  To generate `API Token`, refer to [Create and manage API keys](https://help.nudgesecurity.com/en/articles/8890697-getting-started-with-the-nudge-security-api)

  > **Note:** Token expires after 4 weeks of inactivity.
