# __Description__

  Connector for Adaptive Security that imports user and group data.

# __Overview__

  Adaptive Security is a security awareness training platform that helps organizations
  protect against phishing and social engineering attacks.

  This connector imports users and groups from Adaptive Security into Surface Command.

# __Documentation__

  ## __Setup__

  The connector requires an API Token to authenticate with the Adaptive Security API.
  API documentation: https://developer.adaptivesecurity.com/api
  Required permissions: Ability to generate API tokens in the Adaptive Security admin console.

  ### Generate an API Token

  1. Log in to the Adaptive Security admin console.
  2. Navigate to **Settings** > **API**.
  3. Click **Generate Token** and copy the value.
  4. Paste the token into the **API Token** field when configuring the connector.
