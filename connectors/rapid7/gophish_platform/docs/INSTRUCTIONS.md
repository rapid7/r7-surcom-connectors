# __Description__

  Connector for Gophish phishing simulation and security awareness testing.

# __Overview__

  Gophish is an open-source phishing toolkit designed for businesses and security professionals to test and enhance their organization's defenses against phishing attacks.

  This connector integrates phishing campaigns and target groups from Gophish with the Rapid7 Platform, providing visibility into phishing awareness testing activities.

# __Documentation__

  This connector requires a `Base URL`, `API Key` and `Verify TLS` setting to connect to the Gophish API.

  ## Obtaining API Credentials

  1. Log in to your Gophish admin console
  2. Navigate to **Settings** > **API**
  3. Generate a new API key or copy an existing one
  4. Use this API key in the connector configuration

  For more information on Gophish API Key generation and usage, refer to the [Gophish API Key documentation](https://docs.getgophish.com/api-documentation).
