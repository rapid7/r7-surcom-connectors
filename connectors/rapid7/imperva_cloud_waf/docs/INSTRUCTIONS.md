# __Description__

  Imports accounts and websites configured in Imperva Cloud WAF into Surface Command.

# __Overview__

  Imperva Cloud WAF protects websites and applications from web attacks and distributed denial-of-service attacks.
  This connector imports accessible Imperva accounts and their configured website inventory, including each website's reported status, into the Rapid7 Platform.

# __Documentation__

  ### Prerequisites

  An Imperva user with permission to read accounts and websites is required. API functionality is limited by the roles, permissions, and subaccount access assigned to that user.

  ### Generate the API Credentials

  1. Sign in to the Imperva Cloud Security Console.
  2. Open the API key management page for the user that will run the connector.
  3. Create an API key with permission to read the required accounts and websites.
  4. Save the generated **API ID** and **API Key**. The API Key must be stored securely.

  For additional information, see the [Imperva API authentication documentation](https://docs-cybersec.thalesgroup.com/bundle/api-docs/page/api/authentication.htm) and [API Key Management](https://docs.imperva.com/bundle/cloud-application-security/page/settings/api-keys.htm).

  ### Configure the Connector

  * **API ID**: Enter the API identifier generated by Imperva.
  * **API Key**: Enter the API key generated by Imperva.
  * **Account ID**: Optionally enter an Imperva account ID. When set, only that account and its websites are imported. Leave this empty to import the account associated with the API credentials and its websites. When the credentials belong to a Reseller (parent) account, any managed accounts and their websites are imported as well.
