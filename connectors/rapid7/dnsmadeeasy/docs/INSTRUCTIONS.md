# __Description__

  Connector for DNS Made Easy 

# __Overview__

  DNS Made Easy provides high-performance managed DNS services to ensure increased uptime, reduce IT workload, and boost performance.

  This connector imports details of managed domains into the Rapid7 Platform.

# __Documentation__

  The connector requires the URL of the DNS Made Easy API (typically `https://api.dnsmadeeasy.com`), and an API Key and Secret Key for authentication.

  Follow the steps [here](https://support.dnsmadeeasy.com/hc/en-us/articles/34326955127451-Finding-or-Generating-API-Keys-In-DNS-Made-Easy) to generate the API credentials.
